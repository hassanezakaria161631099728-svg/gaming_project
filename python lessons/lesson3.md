الدرس 3: العمليات الحسابية

تدعم بايثون كل العمليات الحسابية، وفيها عمليات مفيدة مثل القسمة الصحيحة والباقي.

|operation|             |symbol|         |example|           |result|

addition                +             17+5               22

sustraction             -             17-5               12

multiplication *   17*5     85

division       /   17/5     3.4

Integer division // 17//5   3

Remainder        %  17%5    2

power      **        17**2  289  

a = 17

b = 5

print(a + b)    # 22

print(a / b)    # 3.4

print(a // b)   # 3

print(a % b)    # 2

print(a ** 2)   # 289
💡 العملية ‪%‬ مفيدة جداً: إذا كان ‪n % 2 == 0‬ فالعدد زوجي.

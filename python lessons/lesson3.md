a = 17

b = 5

print(a + b)    # 22

print(a / b)    # 3.4

print(a // b)   # 3

print(a % b)    # 2

print(a ** 2)   # 289
💡 العملية ‪%‬ مفيدة جداً: إذا كان ‪n % 2 == 0‬ فالعدد زوجي.
